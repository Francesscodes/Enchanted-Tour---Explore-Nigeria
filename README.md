 Enchanted Tour - Explore Nigeria

A beautiful, interactive landing page showcasing Nigeria's hidden gems and breathtaking tourist destinations. This responsive web application features an elegant image slider highlighting some of Nigeria's most enchanting locations.

 Features

- Interactive Image Slider: Smooth transitions between different tourist destinations
- Keyboard Navigation: Use left/right arrow keys to navigate through slides
- Responsive Design: Fully optimized for mobile, tablet, and desktop devices
- Elegant Animations: Fade-in effects and slide reveals for enhanced user experience
- Modern UI: Clean, minimalist design with intuitive navigation
- Mobile-Friendly Menu: Collapsible navigation menu for smaller screens

Featured Destinations

The landing page showcases four stunning Nigerian tourist destinations:

1. Obudu Cattle Ranch - Nigeria's Mountain Paradise with cool weather and scenic mountain views
2. Agbokim Waterfalls - A magnificent seven-tier waterfall in Cross River State
3. Ibeno Beach - One of the longest sandy beaches in West Africa, located in Akwa Ibom
4. Oguta Lake - A tranquil freshwater lake in Imo State perfect for relaxation

 Technologies Used

- HTML5 - Semantic markup structure
- CSS3 - Custom styling with flexbox and CSS Grid
- Vanilla JavaScript- Interactive slider functionality
- 12columns.css - Responsive grid system by Katherine Kato
- Ionicons - Icon library for navigation
- Google Fonts (Barlow) - Modern typography

 Installation

1. Clone the repository:
```bash
git clone https://github.com/francesscodes/enchanted-tour-nigeria.git
```

2. Navigate to the project directory:
```bash
cd enchanted-tour-nigeria
```

3. Open `index.html` in your browser or use a local development server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

 Usage

 Navigation Controls

- Next/Previous Buttons: Click the arrow buttons to navigate between slides
- Keyboard Controls:  - Press `→` (Right Arrow) to go to the next slide
  - Press `←` (Left Arrow) to go to the previous slide
- Mobile Menu: Click "Menu" icon to reveal navigation links on mobile devices

Customization

You can easily customize the landing page by:

1. Adding More Destinations: Duplicate a `slider-item` in `index.html` and add your content
2. Changing Colors: Modify color values in `style.css` (e.g., `#07d100b2` for the highlight color)
3. Adjusting Animation Timing: Edit the animation durations in the `@keyframes` section
4. Updating Images: Replace images in the `Images/` folder with your own (maintain aspect ratio for best results)
